# Coordinate Project 3

One coordinator selects work; one accountable owner carries each Delivery through its full promise.
Root sets priorities and resolves genuine exceptions. Use [Atlas](../atlas/SKILL.md) and the
[work-board core](../work-board/SKILL.md), including its common execution and effect-specific references.
Scope is FS-GG organization Project 3, including complete unfiltered All items. Use the authenticated
qualified installed caller and protected enrollment, or explicit Root pending-batch admission.

1. Recover membership, existing owners, worktrees, PRs and unresolved original effects. Continue
   unambiguous owned work before creating another assignment. Missing metadata triggers intake;
   it does not hide cards.
2. Select executable Deliveries by user priority, finishing owned acceptance, shared prerequisites
   and aging. Actively seek useful parallel work at entry, after results or changed blockers and
   when another lane waits. Compare actual dependencies, touch-sets, shared surfaces and remaining
   worker, CPU/memory, integrator and hosted-CI capacity. Free slots establish no capacity.
3. Delegate the complete acceptance, permitted actions and limits once through [pnext-item](../pnext-item/SKILL.md).
   Require its native Delivery issue; retain one owner and one integrator per shared surface.
   Ordinary isolated checks need no Root runtime approval. Covered successful steps advance without
   repeated phase approval; changed authority, scope, uncertain effects or exhausted bounds escalate.
4. React to meaningful results. Refresh determining facts, reconcile Delivery Status before its
   Outcome and return to selection. Equal Status is a quiet no-op. One bounded observer owns each
   awaited condition; unchanged ticks stay internal.
5. Accept the whole scoped result, including applicable publication, installation, runtime and
   recovery evidence. Record native acceptance once and capture useful Atlas findings alongside it.
   A merge or all children Done cannot prove Outcome completion.

Keep exact-source validation, independent review, qualified writers and independent effect readback.
Observe uncertain writes before any further send; never renew expired authority. Use existing issues,
PRs and journals, without another scheduler, ledger or phase-worker chain. A user stop ends new
selection immediately. A held programme names its suppliers and reopening conditions; it is incomplete.
