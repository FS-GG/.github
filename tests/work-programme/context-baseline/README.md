## Reproduce without native execution

Run `python3 tests/work-programme/context-baseline/test_collect.py` for synthetic
integrity controls and the sanitized fixture's baseline checks. This launches no
F#, CLR, coordinator, workload or provider tooling.

For an authorized retained window, invoke:

```console
python3 tests/work-programme/context-baseline/collect.py PRIVATE_ROOT PRIVATE_SELECTION NEW_PRIVATE_OUTPUT
```

The selection has schema `fsgg.programme.context-window-selection/1`, stable
`identity`, explicit `helper` identity, and 1–16 `records`. Each record names one
basename ending `.measure.json` and pins `sha256`, `inputSha256`,
`resultSha256`, and `packetSha256` (null for frontier). The collector reads only
those exact helper artifacts. It refuses links, drift, duplicate JSON keys,
undeclared/outside-root paths, malformed populations and unsupported excerpt
windows. It validates every selected full reference body against the packet
input's digest without reading the referenced private file. It never discovers
records by crawling an archive. Output creation is exclusive and mode0600;
use a dedicated private0700 parent directory.

`replay.json` is the sanitized projection of that bounded window, including the
retained evaluation time, active aliases, frontier action kinds, byte/hash
bindings and explicit coverage gaps. It replays baseline accounting only; it is
not a complete frontier snapshot or a replacement for effect authority. Repeating
collection against the same selection produces identical bytes. The fixture
names current compatible helper source at held main
`49a5e93668d4647999cd7171a26d4ad4d151b66b`, SHA256
`bff95c7be46ddeb3594a7efb931f228213a2bfe6f5a1e6d6c5e9a37cdbaeefed`.
Historical measurement files do not record the producing helper executable/source
identity, so that exact historical join remains unknown. Native acceptance is
external.
