# Baseline for scripts/check-pipefail-assertions.py (.github#2689).
# board-paths-live: exempt=Each conversion is opportunistic, so no issue is a maintaining lane until its actual diff changes a counted site.
#
# `<count> <path>` -- how many sites in that file consume the status of a pipeline ending in an
# early-exiting reader (`grep -q`, `grep -m N`, `head`) while the file sets `pipefail`.
#
# THIS FILE ONLY EVER SHRINKS, and the gate is what makes that true. The counts must match the tree
# EXACTLY, not `<=`:
#
#   more than the number here  -> a new site arrived. Repair it. Raising the number is not a remedy.
#   fewer than the number here -> the baseline is STALE. Lower it in the same commit as the repair.
#   a file with sites and no line here -> a new offender in a new file.
#   a line here for a path with no sites -> delete the line.
#
# So a repair cannot land without its decrement, and a decrement cannot land without its repair.
# The file is therefore always a true statement about the tree, which is the property that lets the
# gate be believed at all.
#
# WHY THESE 1186 SITES ARE HERE RATHER THAN REPAIRED. `.github#2681` proposed converting them and
# was closed under the board's filing bar: the sweep would have declared 34 files spanning most of
# `tests/` on a board already reporting `CEILING: 0 worker(s) can start right now`, which is
# `.github#2587`'s lane-starvation failure an order of magnitude larger. `.github#2689` shipped the
# guard instead, so these convert opportunistically -- each inside whatever touch-set already owns
# its file, at zero marginal lane cost. Nobody has to reserve `tests/`.
#
# They are green TODAY only because the outputs they read are small. That is a property of today's
# message lengths, not of the assertions: the hole opens past roughly 16 KB (.github#2668).
#
# TO CONVERT A SITE, use one of the three spellings the gate prints, then decrement the count here.
# `tests/coord-engine-e2e/run.sh` is the worked example -- .github#2668 converted nine sites in it
# and left the helpers (`contains`/`matches`/`matches_i`) that make the safe forms readable.
#
# Its own remaining 7 are the guard machinery and the planted offenders that prove the guard can say
# no; they are quoted shell inside a fixture, not assertions, and they carry `IDIOM-GUARD` for that
# file's own scanner rather than this gate's pragma.
#
# Measured at the tree .github#2689 shipped against: 136 shell files, 130 setting `pipefail`,
# 54 carrying at least one site, 1186 sites in total.
