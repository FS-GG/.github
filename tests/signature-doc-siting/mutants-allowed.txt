# so it needs the same written justification, in the same shrink-only file. `skip:` entries are
# spelled `skip:<site>` and the sweep prints the reason it declined beside the justification here,

# FORMAT — one entry per line:
#
#     <mutant-id>  <the reason this mutant cannot be killed, and what a reader should check instead>

# The id is the one the sweep prints, e.g. `cond-false@312:17` or `dir-drop@FS.GG.Coord.Core`. Ids are
# position-bearing, so they move when the gate moves; the sweep prints STALE entries (allowlisted ids

# output for any input — is a reason, and it must carry the proof, not the assertion. "Hard to test",
# "unlikely in practice", "the corpus does not contain one" and "covered by another leg" are NOT
