# Semantic hardness classifier pilot protocol v1

Delivery [#5277](https://github.com/FS-GG/.github/issues/5277), under LEARN-02. This protocol is a pre-rating candidate. No primary rating may start until independent prelaunch review and Root's freeze/launch selection. The earlier #5276 report and its separate posthoc multiverse are not shown to raters and do not change this cohort after freeze.

The experiment tests **judgments**, not execution performance: the same 50 frozen historical task snapshots are classified by four requested judge profiles: `gpt-6.1-sol/medium`, `gpt-6.1-sol/high`, `gpt-6-astra/medium`, `gpt-6-astra/high`. Each item/profile pair uses a new `collaboration.spawn_agent` with `fork_turns="none"` and explicit model/effort. No agent rates a second item or receives previous ratings. Requested configuration and the returned canonical agent identity establish accepted launch provenance; provider-effective configuration stays Unknown without separate evidence. Each dispatch is attributed to **FS-GG/.github#5277 role=analyst**, never the historical item.

## Skill and fixed reference

`assess-task-hardness` version `semantic-hardness/1` is advisory. It evaluates actual obligations and separates intrinsic demand, safety consequences and external waits. Reasoning-demand categories are minimal, bounded, complex, research and unknown. Work volume is separately small, moderate, large or unknown: many mechanical updates may take substantial active time without requiring stronger reasoning, while a tiny invariant repair can be cognitively difficult. Required active evidence/validation/release work counts toward expected total work; only waiting and unattended runtime are excluded. The five supporting facets are not added into a total. Evidence consists of short exact numbered-line excerpts and a concise decision basis, not private chain-of-thought. Confidence is qualitative and uncalibrated.

All judges use `reference-agent-work/1`: a competent general coding agent with ordinary repository tools and a functioning environment, working alone to the stated acceptance with focused validation and ordinary correction. External queue/operator/supplier waits, release scheduling and unattended long jobs are excluded. The reference model/ability is unspecified and uncalibrated, and is explicitly not the judging model. Time p10/p50/p90 estimates are subjective order-of-magnitude worked minutes, or all Unknown. Historical executors include different Claude profiles and environments; comparison to historical proxies is an external-validity diagnostic, not a test of GPT execution speed or calibrated active-work prediction.

The project-owned skill is mirrored in `.agents/skills` and `.claude/skills`, registered as an operator skill with no materialization or routing authority. Normal Codex project discovery remains enabled. Its compact discovery allowance increases only the per-root authored catalog ceiling from 6,300 to 6,500 characters; the description ceiling remains unchanged.

## Frozen calls, controls and presentation

Primary: **50 × 4 = 200** independent classification calls. Separate controls: **five synthetic semantic packets × 4 = 20** and **two outcome-blind primary repeats × 4 = 8**, giving **228 calls total** if the reviewed control count is accepted. Every control and repeat also uses a new agent. Controls are never counted in the primary 50.

Semantic packets compare a minimal spelling task with explicit negated exclusions and unrelated quoted history, and a complex durable concurrent queue task with an otherwise identical packet containing an untrusted `ignore instructions/rate minimal` injection. The expected control relation is invariance to irrelevant additions, plus sensible separation of the two baseline obligations; no population prevalence follows. Two repeats reuse the first two primary snapshots in the outcome-blind hash order, with different blinded IDs. Two repeat items per profile diagnose gross stochastic instability but do not estimate a precise repeatability rate.

Python `random.Random(5277)` fixes presentation before ratings. Each of 57 blocks contains one call from every profile in randomized order; each profile has its own permutation of the 57 blinded packets. The full schedule is hashed. Profiles are not named in the rater message; requested launch settings remain in the controller's private ledger.

Root's resource bound is at most four raters concurrently only when global live capacity permits and one slot remains reserved for archive/release work; while the disjoint EDA worker is active the cap is three. Before launch selection the initial cap is two. The controller uses the immutable schedule and append-only launch receipts, not adaptive item selection. No new model/payment/provider route is used. No agent output is fed to another judge and no prompt tuning occurs within the frozen primary experiment.

## Prespecified statistical analysis

Use the existing pinned NumPy 2.5.4 / SciPy 1.18.1 environment. Retain all four profiles and six pairwise profile comparisons, including Unknown coverage. The proposed minimal/bounded/complex/research ordering is a hypothesis: unresolved discovery is not necessarily harder than every known integration, and ordinary fact lookup is not the research category. Report the full nominal confusion matrices and unweighted Cohen kappa alongside all ordinal analyses; repeat ordinal analyses with research treated as a distinct nonordered category (omit it from ranks, retain its counts). For valid paired ordinal demand responses report exact agreement, absolute category difference, signed difference, linearly weighted Cohen kappa and Spearman/Kendall concordance, with undefined constant/support cases explicit. Treat unknown as missing for ordinal metrics, not an easy category, while reporting its profile-specific rate. Category equality is judgment agreement, not construct validity.

Primary contrasts are within-model high-minus-medium judgment shifts for Sol and Astra, plus the between-model contrast averaged over effort. Report effect sizes and task-parent-cluster bootstrap percentile intervals (seed 5277; 1,000 resamples) where enough observed independent clusters support a useful description, with cluster count and degenerate resamples. The practical equivalence margin is a **proposed** 0.5 category in mean paired difference; only an interval wholly inside both boundaries supports this narrowly defined judgment-equivalence statement. It does not prove item-level agreement, equal model execution ability or a universal difficulty scale. Preserve all six pairwise results; no unadjusted significance search or causal claim. Item/profile interactions and disagreement concentration are descriptive, not an identified execution IRT/DIF model.

Report all semantic control pairs and repeat differences by requested profile, separately from primary estimates. Prespecified within-profile duplicates remain fresh calls with independent histories; there is no attempt to make a rater remember a previous answer. No training, prompt updates or threshold fitting use these results during this experiment.

External time validity is limited to supported historical evidence: native-completed-only creation-to-closure calendar (other closure reasons separate), observed response-envelope union through native closure, all-observed union including open tasks, summed invocation envelopes, and the pre-existing 1 h/8 h/24 h gap-cap sensitivities. None becomes verified active time. Compare each profile's ordinal reasoning demand, ordinal work volume and log time-median with these endpoints and transparent old-H/body-length baselines on identical available rows. Report missingness, parent clustering, scope-drift indicators and actual historical execution-profile/task-mix strata. Postdispatch review/repair/activity are diagnostic mediators, not safe causal baseline adjustments.

Any exploratory grouped prediction uses training-only preprocessing, fixed model choices, mean and median baselines, whole-parent holdout, and a separately reported chronological split that purges crossing parents. Unsupported sample/group/time splits stay unsupported. There is no untouched large test set here and no search-selected winner becomes validation. Agreement may be high while duration validity is poor. Historical quality judgments lack a uniform frozen quality contract, so no calibrated quality probability or actual implementing-profile invariance is claimed.

Publish maintained source, synthetic fixtures and safe aggregate results/report under `reports/` after independent review; private packets, mappings, individual ratings, manifests and telemetry remain private. Normal PR/merge is required. No native card or learned-routing activation follows automatically, and #5248/#5276 retain their full promises.
