# FS.GG tools

- [`new-sdd-workspace`](../scripts/NewSddWorkspace/README.md) launches the supported interactive workspace wizard.
- The [agent setup guide](consumer/agent-setup.md) tells Codex or Claude Code how to authenticate GitHub, create and secure a product board, and verify the workspace.
- [`fsgg-sdd`](https://github.com/FS-GG/FS.GG.SDD/blob/main/docs/quickstart.md) drives the SDD lifecycle and keeps workspace artifacts coherent.
- [`fsgg-coord`](../src/FS.GG.Coord.Cli/README.md) coordinates claimed work, review, and delivery across FS-GG repositories.
- [FS.GG.Governance](consumer/governance.md) adds optional, workspace-owned rules and gates.
- The [consumer guide](consumer/index.md) covers everyday use, while the [architecture guide](architecture.md) owns design and composition detail.
- The [versioning guide](consumer/versioning-and-updates.md) owns compatibility, feeds, pins, and update policy.
