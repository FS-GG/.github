The repository-owned [work-programme](../../.agents/skills/work-programme/SKILL.md) skill replaces
`work-unified-roadmap` for this programme. It keeps the parent focused on lane frontiers, integration
and decisions; implementation owners retain detailed source investigations and evidence. It is temporary,
does not change generated-workspace defaults, and needs no package release or permanent Host rollout.

The dependency-free F# adapter supplies advisory frontier decisions, pinned bounded packets, streamed
artifact hashing, retained input/result files and private operation measurements. It does not launch
agents, merge PRs, execute workloads or issue acceptance authority. Existing admission, routine delivery,
qualification-selection, telemetry and operation safeguards remain in force. Byte equality is distinct
from signatures, semantic acceptance, complete artifact inventories and process custody.

Acceptance is intentionally short: one offline FSI suite with 31 cases, an actual CLI canary using the
new skill/helper bytes, and the repository's normal skill/catalog/mirror/selector checks. Source delivery
lands as one routine PR. The first separately requested programme run is the operational trial; no extra
rollout programme or live workload is required merely to install the skill.

observations, retained unreadable owners, unknown/failed operations, same-chain owners, pending validation,
late disputes, projection holds, existing PRs, repository PR capacity, unknown capacity, dependency cycles,
