# SVG-REPLAY-01 — replay, inspection, planning and rules

Status: selected after Release B. Route: routine for source and generated-candidate work; any package
publication remains a separately evidenced protected operation.

This is the executable M7 plan for the
[accepted SVG game-engine programme](../2026-09-07-064259-svg-game-engine-template-design-roadmap.md). It
delivers C14–C16 through one deterministic game authority, portable replay evidence, separate planning state,
and scoped formal-rule evidence in installed generated consumers. S.I.R. remains strictly read-only; tactical
compatibility stays a Templates-owned external fixture.

## Stable boundary

- `FS.GG.Game.Core` owns canonical replay identities, ordered inputs, checkpoints, seek and divergence data.
- Replay execution uses the same product transition function as live sessions. Workers, inspectors and exports
  consume that authority and cannot define alternate gameplay semantics.
- Authored, predicted, accepted and committed states carry distinct identities. Prediction and scenario work
  cannot mutate authored content or accepted session history.
- Product-owned rules expose a generic catalog, dependency and explanation contract. Quint is the formal source
  for modeled rules; generated metadata binds the model identity to real implementation correspondence.
- Templates supplies neutral continuous and tactical generated consumers, browser Studio journeys and the
  installed exact-candidate matrix. Player-only bundles exclude planner, rule explorer and worker tooling.

## Milestones

- [ ] **SVG-REPLAY-01.1 — Record, checkpoint, seek and diagnose — route: routine**

  Add portable recorder/checkpoint/seek contracts to Game, cancellation-safe replay execution and a canonical
  export envelope. Qualify matching .NET/Fable results, historical-format rejection or migration, checkpoint
  equivalence and an intentional mutation that reports the first divergent tick/input/state digest.

- [ ] **SVG-REPLAY-01.2 — Separate planning and prediction state — route: routine**

  Add a generic scenario/planning adapter over the real product transition function. Prove authored, predicted,
  accepted and committed identities cannot be confused; support branch/cancel/compare/commit-intent without
  silently changing content or accepted history. Qualify both grid and continuous-coordinate consumers.

- [ ] **SVG-REPLAY-01.3 — Bind rule catalog and formal evidence — route: routine**

  Define a generic rule catalog, dependencies and causal explanations for a non-S.I.R. rule set. Add or amend a
  bounded Quint model, generate versioned rule metadata, and bind model actions/invariants to the actual Game
  implementation with positive and deliberate-divergence conformance evidence. SDD materializes the selected
  author/inspect guidance with explicit backend/profile and freshness checks.

- [ ] **SVG-REPLAY-01.4 — Qualify generated Review and Plan tools — route: routine**

  Compose replay timeline, inspector, planner, scenario comparison and rule explorer in the optional Studio
  bundle. Run exact generated candidates in Chromium, Firefox and WebKit for record/replay/seek, cancellation,
  divergence diagnosis, planning separation, rule explanation, disclosure filtering and accessible keyboard
  operation. Prove the production player bundle excludes analysis modules.

- [ ] **SVG-REPLAY-01.5 — Close M7 and select networking — route: routine**

  Reconcile C14–C16, M7 and section 13 replay/disclosure evidence against exact source and generated-candidate
  identities. Record package/public availability separately, keep Release C open, and select
  `SVG-NETWORK-01` only after all required replay, planning, rules and implementation-correspondence checks pass.

## Completion boundary

This milestone completes C14–C16 and M7 at the source/generated-candidate boundary. It does not claim public
Release C artifacts, multiplayer/resync, integrated scale, complete C20 delivery, Release D, or lifecycle/default
activation. Those remain owned by their later roadmap stages and explicit evidence boundaries.
