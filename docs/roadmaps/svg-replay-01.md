# SVG-REPLAY-01 — replay, inspection, planning and rules

Status: complete at the source/generated-candidate boundary. Route: routine for source and generated-candidate
work; package publication remains a separately evidenced protected operation owned by Release C.

This is the executable M7 plan for the
[accepted SVG game-engine programme](../2026-09-07-064259-svg-game-engine-template-design-roadmap.md). It
delivers C14–C16 through one deterministic game authority, portable replay evidence, separate planning state,
and scoped formal-rule evidence in installed generated consumers. S.I.R. remains strictly read-only; tactical
compatibility stays a Templates-owned external fixture.

## Stable boundary

- `FS.GG.Game.Core` owns canonical replay identities, ordered inputs, checkpoints, seek and divergence data.
- Replay execution uses the same product transition function as live sessions. Workers, inspectors and exports
  consume that authority and cannot define alternate gameplay semantics.
- Authored, predicted, accepted and committed states carry distinct identities. Prediction and scenario work
  cannot mutate authored content or accepted session history.
- Product-owned rules expose a generic catalog, dependency and explanation contract. Quint is the formal source
  for modeled rules; generated metadata binds the model identity to real implementation correspondence.
- Templates supplies neutral continuous and tactical generated consumers, browser Studio journeys and the
  installed exact-candidate matrix. Player-only bundles exclude planner, rule explorer and worker tooling.

- [x] **SVG-REPLAY-01.3 — Bind rule catalog and formal evidence — route: routine**

  Define a generic rule catalog, dependencies and causal explanations for a non-S.I.R. rule set. Add or amend a
