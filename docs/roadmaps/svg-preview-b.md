# SVG-PREVIEW-B — installed authoring/runtime preview

Status: selected after `SVG-PRESENT-01` source/generated-candidate completion. Route: routine for preparation
and installed qualification; protected operation for publication.

This is the executable Release B plan for the [accepted SVG game-engine programme](../2026-09-07-064259-svg-game-engine-template-design-roadmap.md)
and the [Unified Roadmap feature index](../2026-09-07-154210-fs-gg-unified-development-roadmap.md#98-feature-parts-and-subroadmap-index).
It publishes the source-complete authoring, input, runtime, animation, browser-audio, save, and browser-storage
set and proves those exact public bytes through clean and upgraded installed receivers. S.I.R. remains strictly
off limits; tactical compatibility stays a Templates-owned external fixture.

- Templates publishes `FS.GG.Workspace.Template` at **0.12.0** and pins those exact public versions in the SVG
  composition.
- The workspace wizard remains at its current public version and is qualified through its bounded two-step
  adopter. SVG remains opt-in; no provider, lifecycle, coordination epoch, or general default changes here.

## Custody and recovery

Each producer prepares and validates its complete release roster before any tag or feed mutation. A release
packs once and retains authenticated original archives. Both feeds receive those same originals, and readback
compares archive payload members while allowing only nuget.org's explained signature addition. After a package
or tag exists, recovery replays only retained original bytes; it never deletes or retargets a tag, overwrites a
package, or reconstructs a partial release.

The published producer set is a dependency of Templates adoption. A successful source merge, one-feed push,
or metadata listing does not satisfy the public-input boundary. Templates publication failure does not erase
verified producer releases, but Release B remains incomplete until the installed public matrix passes.

- [ ] **SVG-PREVIEW-B.5 — Qualify installed public receivers and close Release B — route: routine**

  From isolated public-only caches, install Templates 0.12.0 through direct, SDD, typed/profile-2, current

  Bind .NET/Fable correspondence and producer evidence to the downloaded public bytes. Only after readback and
  the installed matrix pass may Release B be marked complete and `SVG-REPLAY-01` selected.

## Completion boundary

Release B claims a supported installed authoring and local-play preview through M3–M6 and C04–C13. It does not
claim replay/planning/rules, multiplayer, integrated scale, complete C20 delivery, Release C/D, or any lifecycle
default activation. The projection must report product capability, public package availability, installed
workspace compatibility, and activation as distinct facts.
