## Process problems we can fix

- **Too much timing and sequencing still lives in conversation.** Root-issued deadlines and repeated message-based phase handoffs have lost usable operating time. Some later decisions arrived with little room for remaining work. Root should freeze the actual controller, limits and continuation predicates before granting the operation, then start and record its clock inside that controller before preflight. Covered successful steps should advance without another conversational handoff. Uncertain effects still require retained readback; expired windows must remain expired.

- **CLI, context and intake checks arrive too late.** Unsupported invocation details and missing Roadmap data have stopped otherwise prepared work at execution entry. The #5175 gate correctly refused before a source send, and its owned field repair is now qualified. Root and each full owner should validate the real command/context and complete the selected intake before reserving an expensive execution window. Reuse the prepared candidate and accepted evidence after that repair; do not restart unrelated validation.

- **An early CI observation was weaker than the acceptance being sought.** “Checks present” with zero created jobs did not establish a complete required DAG. Subsequent original-run qualification supplied the actual population. The source owner should arm one bounded observer against the expected workflows, attempts, actual jobs, required contexts and tested checkout. A present-only response is an intermediate observation. This improves the interpretation of existing checks without adding another watcher or rerunning CI.

- **Independent review is finding consequential defects.** It caught real filesystem/input-injection and cleanup problems, along with provenance and scope claims that needed correction. These reviews protect acceptance and should remain. Root and the same critic should review only the changed boundary on repair, reuse unchanged source, package and measurement proof, and retire the previous local observer before arming its replacement. The expected reduction in repetition is plausible; its token and elapsed-time benefit is not measured.

These are owned process findings, not a new reporting ledger. Root owns controller timing and intake sequencing; the retained delivery owners own command correctness, observation and repair. Reconsider each disposition when ordinary execution supplies new evidence of recurrence or a genuinely changed requirement.
