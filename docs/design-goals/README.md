# Current design goals

These pages summarize the target architecture FS.GG is working toward. They are
orientation, not a second authority: the linked ADRs, designs, issues, and roadmap
own the exact contracts. Unless the [status page](implementation-status.md) says a
capability is live, treat it as a design goal rather than shipped behavior.
