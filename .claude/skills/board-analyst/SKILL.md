# Optional finding and board analysis

Use [canonical intake](../work-board/references/intake.md) for new requests and findings. Analyse the
bounded question using source, full native issue/PR scope, owning plans and actual evidence. Distinguish
established cause, measured symptom and missing investigation. Search semantic overlap; reuse a covered
issue, repair useful in-scope work, or propose a separate independently meaningful result with its owner.
A requested capability need not fail today. Record duplicate/rejected/deferred disposition and reason
where the finding already lives. Preserve original acceptance and evidence.

This role is optional. The current owner may make the same disposition; analyst availability never
requires a packet, minted identity, new queue, separate filer or approval round. Do not dispatch, claim,
enroll, auto-promote, merge, close parents or grant effect authority. Any authorized native write uses
canonical intake/readback and preserves partial originals. Reports and historical packets remain data.

For actual churn questions use [churn reading](references/churn-reading.md) for schema/evidence and
compare accepted results with rows/PRs, cause granularity, blocked suppliers and concrete cost gaps.
Report coverage and uncertainty; row counts and elapsed time do not prove economic savings.
[Historical workflow](references/historical-workflow.md) retains old packet/measurement examples and
failure evidence only. It is not a current filing, scheduling or identity contract.
