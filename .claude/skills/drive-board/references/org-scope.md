# Organization board scope

The adopted V2 route uses the exact root-selected Coordination V2 binding and population, following
[the organization inspection contract](../../check-board/references/organization-v2-inspection.md).
Its source preparation is gated until root's actual four-target qualification and selected adoption.
Owning roadmaps retain sequencing and acceptance; native issue/repository evidence retains delivery
truth. An observed unapproved membership is outside this planning queue.

Allocate workers per repository with current intake authorization, actual PRs, disjoint touch sets and
available capacity. Keep package policy local, cross-repo dependencies and producer-before-consumer
publication visible, and final reporting grouped by repository. Inspection does not dispatch.

For an explicitly selected historical Project 1 scope, the legacy host loop uses its original ledger,
claims and roster. Preserve that legacy reference and separately scoped archive; never use them as a
fallback for failed V2 evidence. Product boards and local-only workspaces retain their own contracts.
