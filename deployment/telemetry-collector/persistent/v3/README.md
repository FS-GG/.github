# Persistent receiver v3 preparation

This directory contains an inert, stateless F# preparation boundary for a future persistent receiver v3 installation. It validates explicit public artifact identities, the manager `/3` command, source-reference `/3`, the canonical verifier, its complete declared runtime inventory, and recovery coverage. Its output always remains inactive and makes no installed, custody, capture, or native-acceptance claim.

`identityClass=synthetic-test` is reserved for controlled fixtures and cannot establish public artifact readiness. No artifact version is assigned here. Registration in shared solutions, persistent image wiring, publication, installation, enrollment, activation, backup execution, and roadmap projection remain root-owned joins.
