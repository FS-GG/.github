READING THE SIGNAL

What this view can say

01

Bounded by design

Actions metrics describe the newest capped sample and show its exact observed time span. Completed-run spans measure start to last update, not runner time. They are not a full date-window total.

02

Unknown stays unknown

Missing model, effort, price, human time or host evidence never becomes zero, compliant or inferred.

03

Budget authority stays local

The canonical reducer owns the 5% target, 10% ceiling, breach count and verified intervention reset. This page only renders its verdicts.
